# Requirements

- Configure the app icon and implement a splash screen during app startup
- Must have a form with multiple inputs
- Must have a Home screen with a list greater than 1000 items
- Must have a screen using Camera and Image Picker (We can use free API to upload Photos or use local URI)
- Apply Linking
- Push Notifications using Firebase Cloud Messaging
- Optimize application performance
- Apply Firebase Performance Monitoring and Crashlytics

# Getting Started

| Command                                                               | Action                       |
| --------------------------------------------------------------------- | ---------------------------- |
| `git clone git@gitlab.asoft-python.com:huy.phamnhat/react-native.git` | Clone repository from GitLab |
| `git checkout advanced-practice`                                      | Checkout branch              |
| `npm i`                                                               | Install dependencies         |
| `npm run android`                                                     | Build and run                |
| `npm run storybook-generate`                                          | Generate storybook           |
| `npm run test`                                                        | Run all test cases           |
| `npm run coverage`                                                    | Coverage all test cases      |
